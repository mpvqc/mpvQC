mpv-winbuild-cmake project:
  https://github.com/shinchiro/mpv-winbuild-cmake

libmpv
  Description: mpv media player library
  Homepage: https://mpv.io
  License: GPL-2.0-or-later
  License File: GPL-2.0-or-later.txt

ffmpeg
  Description: Multimedia framework linked into libmpv
  Homepage: https://ffmpeg.org
  License: GPL-3.0-or-later
  License File: GPL-3.0-or-later.txt

Media dependencies
  Description: Further libraries linked into libmpv, such as libass and libplacebo

Flatpak Build
-------------

The Flatpak builds libmpv and its media dependencies from build recipes taken
from flathub's io.mpv.Mpv:
  https://github.com/flathub/io.mpv.Mpv

libmpv
  Description: mpv media player library
  Homepage: https://mpv.io
  License: GPL-2.0-or-later
  License File: GPL-2.0-or-later.txt

ffmpeg
  Description: Multimedia framework libmpv is built against
  Homepage: https://ffmpeg.org
  License: GPL-3.0-or-later
  License File: GPL-3.0-or-later.txt

Media dependencies
  Description: Further libraries built and shipped alongside libmpv, such as
               libass, libplacebo, vapoursynth and zimg
